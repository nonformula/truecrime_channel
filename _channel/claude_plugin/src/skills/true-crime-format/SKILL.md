# True-crime editorial format — v3.2

Read `references/rules.md` and `references/story-format.md` for editorial work. For source/data questions read `references/data-contract.md`; for production implementation read `references/later-stages.md`. Load `references/pilot-darkhorse.md` only for DARKHORSE-specific guidance.

Create an evidence-driven investigative thriller from permitted primary sources. Runtime 15–30 minutes, with authentic moments, clear investigative graphics and purposeful labeled recreations. Narration draws on the named device set (analysis, audience question, foreshadowing, emphasis, connect the dots, knowledge ledger), varied rather than repeated. Structure follows the case, not a fixed chapter count or quota. Keep the victim present throughout.

This package supplies stage instructions and Drive document schemas. It does not supply a media engine, editor, background worker or independent fact-checking service. For action requests use the matching bundled stage procedure; for general format questions answer without writing case outputs.

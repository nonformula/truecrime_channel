# Full source-linked script — stage 6a

Read `references/rules.md`, `references/drive-workspace.md`, `references/data-contract.md` and `references/gates.md` before working on a case. These references are bundled with this skill. Read `references/story-format.md` and `references/segment-format.md`.

Read the approved pre-script first, then the brief/spine, opening-test outcome, selects and evidence. Expand the pre-script; do not restart from the spine. If the pre-script is not approved, stop at that gate unless the user explicitly consolidates gates (record the decision). If the opening assembly does not yet exist, proceed with that dependency identified. Do not silently rewrite the approved structure or mark an untested opening approved.

1. Write a complete Script Doc in segment blocks, carrying the pre-script's VO lines, sound bites and ledger moments forward and adding exact footage references and visual element IDs. Authentic audio/footage get equal structural treatment to VO. Keep device use varied and emphasis reserved, per `story-format.md`. Never write or synthesize case-participant speech. Each factual line, quote, screen claim and panel state has precise EVD links. Keep knowledge dates and reveal order distinct.
2. Build tension from discoveries, contradictions and consequences. Cut repeated explanation, preserve context, distribute human detail and end on the person. Do not fill thin evidence with cinematic inventions.
3. Create/update Production Plan Sequence and VO tabs. Estimate a combined sequence first; use measured timings only when source intervals or actual reads support them. Reconcile act totals with the spine.
4. Assign stable SEG and VO IDs. Do not generate temp VO here; that is stage 6b (`case-tempvo`) and runs only after this gate passes.
5. Review line-by-line factual support, quote continuity, source use and unresolved checks. Reconcile accepted changes to beats/selects. Save and read back the script and timing tables.

Gate: producer review of the complete source-linked script, with unsupported factual claims resolved or removed. Freeze identifiers, not the ability to revise wording. Report creative strengths/remaining weaknesses and estimated runtime against 15–30 minutes. Next is temp VO (`case-tempvo`), then visual planning.

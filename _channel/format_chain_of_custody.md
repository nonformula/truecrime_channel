# Format: Chain of Custody

The episode is built from evidence, one object at a time, by a narrator who already knows the ending.

## Structure

| Block | Time (approx.) | Job |
|---|---|---|
| **Cold open** | 0:00–2:30 | Real footage of the strongest dramatic-irony moment. Narrator states what the viewer knows that the people on screen don't. Ledger appears. |
| **Exhibit 01** | | Establish the victim as a person (their own voice/clips) and the relationships (graphic). |
| **Exhibits 02–05/06** | 5–8 min each | Each opens on one evidence object as an exhibit card. Each ends on an open question the next exhibit answers. |
| **Baseline beat** | inside an exhibit | Where interview footage allows: one person is the baseline, the suspect is read against it. |
| **Close** | 3–5 min | Verdict, sentence, aftermath. End on the victim. |

## Channel devices

- **Exhibit card** `[EXHIBIT: E###]`: chapter opener. Number, object name, one-line descriptor, source.
- **Knowledge Ledger** `[LEDGER]`: two columns, *What police know* vs *What you know*. Updated from narration. When the columns match, the case is closed.
- **Day counter**: optional, for manhunt or timeline-pressure cases.
- **POV lenses**: assigned per person in the brief (`lenses/`).

## Retention rules

- Strongest real footage inside the first 90 seconds.
- Every chapter exits on an open question.
- Peaks get silence. VO covers about 65–70% of runtime.
- Recreations roughly 20–25% of runtime. Real footage is the backbone.

## Recreation slots the format usually needs

Use these to suggest the 3–5 recreation candidates in every brief:

1. **The victim's ordinary moment** before events turn (their lens, life-affirming, stops before harm).
2. **The approach**: a documented movement toward the scene (vehicle, route), never the act.
3. **The aftermath action**: a documented step after the event (selling, discarding, travelling).
4. **The escape or concealment**: airport, border, new identity, if documented.
5. **The capture or confrontation**: from the subject's lens, cutting to real footage of the moment.

Not every case has all five. Drop any that fail the recreation rules.

# Verify chronology and authentic selects — stage 2

Read `references/codex-runtime.md` for Codex tool discovery and execution boundaries.

Read `references/rules.md`, `references/drive-workspace.md`, `references/data-contract.md` and `references/gates.md` before working on a case. These references are bundled with this skill. 
Read the current indexes, chronology, report and relevant originals; load `references/story-format.md` for narrative selection.

1. Prioritize claims needed for the hook and central investigation. Reconcile dates, time zones, source-clock offsets and investigator acquisition dates. Keep each contradiction and its effect on the proposed story visible.
2. Log proposed selects in the Selects Sheet with exact original in/out, context and unique purpose. Check quoted words by listening, visual assertions by viewing, and document claims against exact pages. Match source version and transcript version. Never manufacture subsecond precision from a transcript that does not supply it.
3. With only transcript/document tools, produce a useful verification queue containing asset links, time ranges, proposed claims, requested check and owner. Leave audiovisual selects unreviewed; state the capability limit. Do not mark the gate passed because a transcript sounds plausible.
4. Update Evidence, Events, Conflicts, People/Locations and source coverage from actual checks. Keep acquired/approved-for-use statuses separate. For a witness allegation, verify attribution rather than declaring the allegation proved.
5. Summarize what the hook can support, what needs narrowing and which issues block it. Save a verification section in the Research & Ingest Report and exact reviewed revisions in the Case Record.

Gate: the central hook/connections have adequate source support and selected excerpts have the required checks, followed by producer review. Drafting a narrower supported brief can continue while unrelated checks are pending. Return the Selects link, principal findings, blockers and proposed next step.

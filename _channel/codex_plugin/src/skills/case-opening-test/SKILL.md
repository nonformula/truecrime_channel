# Opening-five-minutes test — stage 5

Read `references/codex-runtime.md` for Codex tool discovery and execution boundaries.

Read `references/rules.md`, `references/drive-workspace.md`, `references/data-contract.md` and `references/gates.md` before working on a case. These references are bundled with this skill. Read `references/story-format.md`, `references/segment-format.md` and for DARKHORSE `references/pilot-darkhorse.md`.

Read the brief, spine, selects and existing approvals. Produce the Opening Test Doc with a timed opening script and assembly instructions. Include segment IDs, exact source in/out, factual citations, narration text, separate picture/sound, labels, transitions, holds and unresolved dependencies.

Use the 90-second conflict/question opening for DARKHORSE, followed by discovery, Mo and the evening evidence. Other cases use their approved hook. Use authentic moments plus simple graphics/stills; avoid commissioning full recreation motion before this test.

Two explicit outcomes:
- If authorized media/editing tools and inputs are available, assemble a watchable test, link the export/project, measure runtime and inspect the actual result.
- Otherwise deliver an opening paper edit and editor handoff. State “assembly pending”; assign exact source checks/assets and the next action. Do not label a paper edit an animatic, measured cut or passed opening test.

Evaluate the actual assembly when available: Does the hook raise a clear question? Does momentum survive the title? Is the victim present? Are dates and source/reconstruction boundaries clear? Does narration add necessary context? Are repeated points removable? Test reduced VO where original audio already communicates the point.

Record changes to spine/script IDs and the chosen narration/graphic approach. The gate applies to the watchable assembly plus producer review. A producer may request the pre-script or a development script while assembly is pending; retain that dependency visibly and do not imply the test passed. Next is the pre-script (`case-prescript`).

# Production and release — stages 7–12

Read `references/codex-runtime.md` for Codex tool discovery and execution boundaries.

Read `references/rules.md`, `references/drive-workspace.md`, `references/data-contract.md` and `references/gates.md` before working on a case. These references are bundled with this skill. Read `references/segment-format.md` and the requested section of `references/later-stages.md`.

Determine the requested stage from the user and current case record. Inspect current approvals and inputs. Carry out the specified work using available connected tools, save native production documents and link generated media. Do not assume a local tool exists because the system document names it. Map generation (stage 7) follows the Mapbox specification in `later-stages.md`.

State capability gaps as specific pending work. A shot brief is not a generated shot; an edit list is not an assembly; a checklist is not completed review; a release package is not publication. Complete all useful authorized preparation, then leave a concrete handoff with inputs, required action, owner if known and completion criteria.

Record exact artifact revisions and review outcomes in the Case Record. Return links, completed versus pending work, and the next useful action. Preserve all stage and source invariants in the shared references.
